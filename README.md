# SillyTavern Breeze 角色语音 · 0.6.1

读取 `[TTSVoice:角色名:情绪:对白]`，连接原 Breeze WebUI，把当前聊天中已绑定音色的对白生成为 WAV 并按顺序播放。从酒馆输入栏的魔棒菜单进入独立语音工作室。支持参考音频方向设计、共用音色库及流式播放；0.6.0 将额外语料升级为可命名、跨聊天复用的语料库，每个聊天单独选择和启用。

## 两个工作区

- **TTS**：仍在上级 `G:\study\AI\breeze-tts`，打开 `TTS.code-workspace`。后端代码为 `breeze_infer/voice_service.py`，接入原 `webui.py` 和 `breeze_infer/api.py`，共用已加载模型及推理锁。
- **酒馆插件**：本目录，打开 `酒馆插件.code-workspace`。`extension/` 是可安装扩展，无运行时 npm 依赖。原有酒馆预设、世界书、参考和实验文件已分类迁入此目录；迁移清单为 `relocated-files.json`。
- 音色和合成文件保存在原 TTS 的 `data/tts/`，不放入插件。映射和音频缓存引用存于酒馆当前聊天的 metadata。

## 安装与首次使用

1. 重启更新后的 Breeze WebUI，让新增的 `/breeze/*` 路由生效，然后在 WebUI 加载模型（或通过「设置」开启下次启动自动加载）。无需另开 TTS 服务。
2. 把 `extension/` 内的全部文件复制到：

   ```text
   G:\study\AI\SillyTavern-Launcher\SillyTavern\data\default-user\extensions\sillytavern-breeze\
   ```

   目录下应直接包含 `manifest.json`、`index.js`、`panel.js`、`panel.css`、`stream-player.js`、`extra-prompts.js` 等文件。其他酒馆用户使用其自己的用户目录。也可解压 `dist/sillytavern-breeze-0.6.1.zip` 到该用户的 `extensions/`。更新时复制全部扩展文件并刷新酒馆；参考方向和流式任务需要配套新版后端，0.4.0 及以上升级到本版的预设界面无需重启 TTS。

   本目录提供安装脚本，复制前会备份已有同名扩展：

   ```powershell
   .\install.ps1 -SillyTavernPath 'G:\study\AI\SillyTavern-Launcher\SillyTavern'
   ```

3. 刷新酒馆页面，点击输入栏左下方的 **魔棒 → Breeze 语音工作室**。在「连接与播放」填写地址，默认为 `http://127.0.0.1:7860`，点击「保存并连接」。
4. 在「本地音色库」展开「导入参考音色」直接保存已有音频和准确文字。需要创造新声音时，在「声音设计室」选择「文字设计」或「语音方向」：前者填写描述，后者上传参考音频与准确文字（可试听上传的参考，声音描述可留空），再填写试听文本和候选数量，生成、试听后命名保存。
5. 打开一个聊天，在「角色与音色」给角色选择音色，可以搜索角色并直接试听已绑定声音。初始映射为空，未映射角色跳过；多个角色可以共用同一个音色。
6. 先点击已有对白气泡试听，再按需要打开「自动生成」或「自动播放」。两者默认关闭；自动播放开启时会同时生成。仅处理完成的新回复，加载历史不会自动朗读。

7. 「预设注入」默认开启。插件在每轮生成前通过酒馆 `setExtensionPrompt` 注入英文 TTSVoice 规范，自动填入当前聊天角色、已绑定／未绑定名单与当前语气词列表。默认四个语气词，可直接在面板编辑；额外语料可命名保存，再由各聊天选择和启用。无需再手动复制整段输出规范。

开启后建议关闭手工重复添加的 **TTS 输出规范条目**，避免两份版本同时约束模型。保留 TGbreak 原有剧情、格式、咪咪吐槽等要求，以及原思维／格式里允许 TTSVoice 的兼容规则。插件只增补自己的扩展提示词，不修改已保存的预设文件、提示词顺序或历史消息。

### 流式生成与播放

在「连接与播放」开启「流式生成与播放」（默认关闭）。点击对白气泡、播放本条或自动播放时，新的合成任务会边生成边传输音频；浏览器收到首段即可开始播放。当前句播放完再进入下一句，暂停、继续、音量及停止仍可使用。

生成完成后保留完整 WAV 和原有聊天缓存引用，下次点击直接重播；仅预生成时仍使用完整音频流程。切换聊天、修改消息或停止会中止流式播放并取消未完成任务，未完成音频不写入聊天缓存。后端仍按原队列串行推理。

需要重启新版 Breeze 后端；不支持流式的旧后端会提示更新或关闭该开关。浏览器自动播放权限仍适用，首次可能需要手动点击一次气泡。这里的流式针对 TTS 音频，仍在 LLM 整条回复完成后解析对白；尚不处理正在输出中的半句文字。

### 预设注入设置

- 支持独立开关、英文模板编辑、保存、恢复默认。预览以已保存模板为基础，随语气词列表和当前聊天语料实时更新；这两栏自动保存，英文模板本身仍使用「保存模板」。禁用整个插件也会清除其注入。
- 默认以系统角色注入到聊天深度 **1**，即最近一条聊天之前；可改成 0–100。深度 0 更靠近聊天末尾，但不保证比预设里所有其他指令更靠后，也不能保证模型完全遵循格式。
- 普通生成、重生成、swipe、续写和普通提示词预览使用规则；后台 `quiet` 生成（例如摘要）及 `impersonate` 用户代写跳过规则。切换聊天、映射、角色及预设后重新注册，避免残留旧名单。
- 未绑定角色仍输出 `New` 标记，以便发现新角色；播放时跳过。注入中的角色名保持剧情人物名，不用音色库名字替代。
- 内置插槽：`{{primary_character_note}}`、`{{bound_characters_section}}`、`{{skipped_characters_section}}`、`{{unbound_characters_section}}`、`{{vocal_events}}`、`{{vocal_event_example}}`、`{{user}}`。当前跳过名单只包含用户；其他酒馆宏由酒馆发送时处理。预览不是最终完整请求。
- **语气词列表**：所有聊天共用，默认 `[笑]`、`[叹气]`、`[咳嗽]`、`[清嗓子]`。每行一项，也支持中英文逗号、顿号或分号；可省略外层方括号，自动去重。格式无效的项会提示并跳过。清空表示不添加语气词，可一键恢复四项。规则和示例通过上述两个语气词插槽同步更新。
- **额外语料库**：点击「新建并使用」，填写名称与背景、情绪或发声指导；名称在编辑结束时自动保存，内容输入时自动保存并更新预览。名称不可为空或重复。其他聊天直接在下拉框选择已有语料，并开启「在当前聊天启用」即可复用。
- **聊天绑定**：语料库保存在酒馆插件全局设置，每个聊天只保存所选语料的稳定 ID 和启用状态。修改共享内容会影响所有选用它的聊天；需要单独调整时用「复制并使用」。改名不会破坏绑定。关闭开关或选择「不使用语料」保留库中内容；删除需确认，其他聊天的失效绑定不再注入。
- **注入与迁移**：只有当前聊天启用、选中有效语料且内容非空时，才在编译预设末尾追加 `6. Additional scene guidance (current chat):` 和正文。0.5.0 的旧语料在打开对应聊天时自动命名、存入库并绑定，保留原开关及旧文字备份，不反复创建；删除或取消绑定不会重新启用旧备份。
- 升级只迁移未经修改的旧默认模板，替换固定示例为动态语气词示例；自定义模板原样保留。自定义模板需包含 `{{vocal_events}}` 才能同步列表，可用 `{{vocal_event_example}}` 避免示例仍固定使用旧标签。多组语气词预设的管理与切换仍留作后续。
- 0.6.1 明确「正常引号对白 → TTS 副本」必须成对输出，标签不能替代正文；去引号、Markdown 和旁白仅针对 TTS 副本。结尾双向检查：每段对白有标签，每个标签前也有完整对白。此前未经修改的默认模板会在刷新时自动升级；旧回复不会被改写，需重新生成。提示词检查不能保证模型每次遵循。

机制参考 [EchoCore 的提示词注入器](https://github.com/haide-D/SillyTavern-EchoCore/blob/main/frontend/js/prompt_injector.js)，实际参数及生成事件按本机酒馆源码校验。原手工模板保留在 `prompts/` 供对照。

```text
周启明笑着说：“一起去食堂？”
[TTSVoice:周启明:开心:[笑]一起去食堂？]
```

## 已实现

- 魔棒菜单入口与独立工作室：角色、音色库、声音设计、预设、连接五页；桌面和手机布局，样式通过 Shadow DOM 隔离，Esc 关闭并返回入口焦点。切页和关闭时暂停试听。
- 角色卡、群聊成员、历史 TTS 标签及手动角色汇总；映射按聊天隔离。
- 自动注入可编辑的英文 TTSVoice 规范、角色插槽及注入预览；保留 TGbreak 的其他模块。
- 嵌套方括号解析；语气词原样送入 TTS，不限死四项。排除用户、代码、w2g、catsay、摘要等内容；格式异常跳过并提示。
- 原标签位置显示气泡；仅隐藏显示层标签，原始消息保持不变。其他正则改变显示导致定位失败时，使用消息下方的语音条。
- 单句播放、暂停／继续、整条播放、音频缓存和顺序播放；普通模式播放上一句时可准备下一句，流式模式按句边生成边播放。右键气泡清除该句缓存引用，下一次点击重新生成。
- 切换聊天、编辑、切换 swipe、重新生成和停止时中止旧播放，旧请求的结果不会回填到新消息。
- 参考音色上传、列表和试听；文字设计或参考音频方向均支持 1–8 个不同种子的候选，逐个生成、试听和保存。参考方向每个候选独立提交音频与准确文字，保存的参考文字来自被选候选的生成文本，不是上传参考的文字。
- WebUI「合成 → 已保存音色」可以读取同一音色库；也可在 WebUI 生成试听后创建音色，或在「音色库」直接导入参考。酒馆刷新音色库后可立即绑定。

## 使用边界

- 浏览器可能阻止自动播放，按气泡提示点击播放即可。没有标签的漏标对白不会被猜测补齐。
- 第一次连接需先加载模型；远程浏览器使用 TTS 电脑的实际地址，并用 `BREEZE_TTS_ORIGINS` 允许酒馆页面的 Origin。HTTPS 页面连接 HTTP 服务可能被浏览器阻止。
- 取消后立即停止播放；流式推理在后续分块处退出，普通推理结束后丢弃结果。单个任务等待上限 10 分钟。
- WAV 会持续保留。需要清理时先关闭 TTS，再清理 `data/tts/jobs` 的旧任务音频及配套 JSON；保留 `voices` 音色库。气泡缓存失效后可右键重新生成。
- WebUI 和独立 API 二选一运行；不要同时让两个进程使用同一套 `BREEZE_VOICE_DATA`。若确需多实例，应分别指定存储目录。
- 消息内新角色「就地绑定／跳过」和可配置语气词预设组仍在计划中。自动 prompt 注入已实现。
