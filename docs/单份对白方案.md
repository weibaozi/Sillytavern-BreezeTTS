# 单份对白方案 · 0.7.0-tag-render.10

当前发布分支为 `main`，延续原 `experiment/ttsvoice-render` 的开发历史。稳定分支 `stable/v0.6.1` 和标签 `v0.6.1` 保留在本地基线 `60df1f8`。TTS 后端与插件独立维护；旁白克隆需要配套后端支持。Git 安装与迁移步骤见 [README](../README.md)。

## 单份输入与显示

```text
周启明拍了拍肚子。
[TTSVoice:周启明:happy:[笑]一起去食堂？]
```

插件在原标签位置显示“一起去食堂？”及播放气泡；对白放入原生 `q` 元素，跟随酒馆 `--SmartThemeQuoteColor` 引号颜色，默认橘黄色。旁白保持原样，不要求“人名：”前缀。原始聊天 `mes`、编辑器原文和原始导出都不改；历史发给模型时仍保留标签。显示内容作为纯文本插入，不执行其中的 HTML 或 Markdown。

未绑定音色仍显示完整对白，只跳过合成。显示时去除当前配置与内置默认的完整语气词标签（`[]`／`()`）；未知括号和未知嵌套组保留。发给 TTS 的文本不做这种显示过滤，保留原发声标签。

## 流式文字与语音时机

「连接与播放」新增「读取流式文本」，默认关闭。开启「显示为对白与气泡」时，模型输出中的未闭合标签也会隐藏角色、情绪等元数据，并逐步显示收到的对白；此时不会合成。只有外层 `]` 闭合后才成为可合成的完整标签，不按标点猜测半句话。

开启「读取流式文本」后，完整标签按自动生成／自动播放设置追加到顺序队列，不打断当前播放。关闭该设置仍实时渲染，只把自动语音延后到整条回复完成。音频「流式生成与播放」独立控制合成音频是否边传边播；两项自动开关都关闭时不会自行合成或播放。

停止、编辑、切换 swipe 或聊天会取消旧队列，旧任务完成后不会继续播放。代码区域、编辑器和原始消息不改；未闭合标签不提交语音，也不会自动补齐原文。


## 旁白朗读

0.7.0-tag-render.5 需要同时更新并重启 Breeze 后端，再刷新酒馆。插件通过健康接口确认真正的克隆支持；旧后端会提示更新，不会静默按声音方向合成。角色对白仍使用原来的情绪控制，预设不变。

在「角色与音色 → 旁白声音」为当前聊天选择本地音色和模式。默认「声音克隆」沿用参考音频的语气与风格，不发送情绪指令，CFG 固定为 1；已有旁白配置没有模式字段时也默认克隆。选择「声音方向」后可编辑情绪，默认「平稳口气，配音」，沿用全局 CFG。切换模式保留已写情绪，各模式音频缓存分开。音色、模式、情绪和旁白切片目标字数随聊天保存；选择「不朗读旁白」关闭，音色失效也会跳过。旁白不加入角色名单或注入预设，不需要模型输出新标签。

播放控件放在右下角固定浮动面板中，滚动长回复时仍可操作；可收起为 Breeze 小条，展开／收起状态自动保存。面板默认跟随最新回复，也可选择已加载的历史回复；播放或准备音频时固定控制当前任务，切换聊天后重新跟随最新回复。「暂停／继续」保留当前进度和剩余队列，生成中也可暂停等待；「停止」结束当前播放并清空队列，也可取消正在重新获取的任务。「重新获取」清除本条已绑定对白与已启用旁白的缓存，逐段强制重新合成（重复台词也重新请求），显示进度，完成后点击播放；不会自动发声。未绑定角色跳过，单段失败后继续处理其余片段。「播放本条」和「自动播放全文」按原文顺序穿插旁白及已绑定角色对白；单个对白气泡仍只播放该句。仅开启自动生成时也会准备旁白音频，已有缓存继续复用。旁白正文外观保持原样，只有旁白的消息也可整条播放。

浮动面板的进度条覆盖本条回复中已绑定角色的对白和已启用的旁白，按原文顺序计算。当前回复文字还在流式输出时不可拖动，文字结束后即可定位；音频已齐全时直接按总时长定位，尚未齐全时先补齐缺少的音频，再从拖动的位置开始播放，不强制重生成已有缓存。准备期间可以停止，切换聊天／编辑回复也会取消任务。暂停时拖动保持暂停，点击继续从新位置播放；拖动到末尾结束播放。拖动定位使用完整 WAV，之后的片段仍按顺序播放，首次语音生成的流式开关保持原设置。

旁白从正文文字提取，普通中英文引号、HTML q／blockquote 和 Markdown 引用内容也朗读；只有 TTSVoice 中的对白交给角色音色。代码、图片、链接目标地址、正文前后模块及咪咪吐槽、摘要等仍不朗读。旁白切片默认目标 100 字，可在旁白声音卡中设置 20–1000 字。跨换行、空行及 HTML 段落按目标内最后一个完整句末合并切片，计数以可朗读字符（含标点）为准，换行分隔不占目标字数；单句超过目标时保留整句，仍受 5000 字请求上限保护。换行只保留空格分隔，不单独发起请求；TTSVoice 对白边界立即切开，以维持正文播放顺序。流式读取在后续文字确定当前片段已无法继续容纳下一句时入队，结束时补读尾段；停止、切换聊天或修改旁白设置会取消旧队列。续写自动播放只读新增部分。

提取依赖文本结构，不识别所有自定义正则和 CSS 隐藏规则；自定义正文外模块需另行接入排除列表。没有 TTS 标签的引号内容统一按旁白读，不猜测说话人；历史双份对白中的普通引号副本也遵循此规则。

## 历史兼容的边界

旧回复可能在普通引号对白后紧邻一个重复标签。新模块 `dialogue-render.js` 只检查紧邻段落的引号全文，按顺序合并该段多个引号内容、归一空白并去掉已知发声标签后，完全匹配才省略重复显示、仅添加气泡。

这是保守启发式，不搜索更早段落、不做模糊或语义匹配。文字改写、额外空行等复杂格式可能仍显示两份；完整对白恰好重复也可能被误判。原文始终保留，不会因显示去重而丢失消息。其他正则若提前删除标签，可能影响定位，沿用消息下方语音条作为回退。

## 提示词及设置隔离

默认英文规则保持五条：实际发言只在标签内出现一次，旁白、动作和心理活动在外；姓名一致、情绪自然、语气词可配置，并检查所有发言及最后两次发言。用户、短信、引文、`<w2g>`、`<catsay>`、摘要及状态栏等既有排除规则保留。未绑定人物仍使用 `New`。

0.7.0-tag-render.3 加强单份对白约束：不在普通正文或第二个标签重复同一句台词，不回放前文对白（剧情中有意复述除外），并明确替代旧的双份对白示例。已绑定角色的情绪可用简短单词或贴合人物、关系及当下情境的发声短语，例如 `softly reassuring`、`playful but hesitant`；仍禁止冒号、方括号和换行。

稳定模板保留在 `settings.promptTemplate`，实验模板单独使用 `tagRenderPromptTemplate`；首次使用实验默认，保存或恢复实验模板不覆盖稳定模板。其他设置继续共用：语气词列表、音色映射、具名语料库及聊天绑定的修改不会因代码回退而自动撤销。启用有效且非空的聊天语料时仍独立追加第六条。

不要同时注入旧双份规则。新文件 `prompts/TGbreak_原思维-格式_单份对白实验版.txt` 仅调整历史兼容片段内的 TTS 要求，其余模块、宏及检查保留；旧文件未改。英文实验模板在 `prompts/酒馆_TTSVoice_单份对白实验版.txt`。用户保存的预设不会被插件自动改写。

## 试用和回退

维护者本地保留稳定版工作区与 0.6.1 安装／源码归档；本 Git 仓库的默认分支为当前单份对白版 `main`。继续开发时打开仓库的 `酒馆插件.code-workspace`。

实验包为 `dist/sillytavern-breeze-0.7.0-tag-render.10.zip`。安装或更新时，在实验目录显式运行：

```powershell
.\install.ps1 -SillyTavernPath 'C:\path\to\SillyTavern' -InstallExperimental
```

安装脚本先备份，再替换原同名扩展。不要另取目录名与稳定版并装或同时启用，否则会共用提示词 key、设置和事件。旁白克隆需同时更新后端并重启，再刷新酒馆生效。

回退时从稳定工作区执行其安装脚本，再刷新酒馆；稳定模板保留在原设置键。Git 分支、标签和源码归档保存代码基线，不转换实验期间产生的聊天。稳定版对实验单份回复可能只显示气泡；标签里的原文仍保留，可查看原文或重新使用实验渲染。
