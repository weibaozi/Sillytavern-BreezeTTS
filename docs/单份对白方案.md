# 单份对白方案 · 0.7.0-tag-render.3

稳定分支 `stable/v0.6.1` 和标签 `v0.6.1` 保留在基线 `60df1f8`。实验分支为 `experiment/ttsvoice-render`，工作区位于 `G:\study\AI\breeze-tts\sillytavern-breeze\branches\ttsvoice-render`。稳定插件仍在 `G:\study\AI\breeze-tts\sillytavern-breeze`，后端仍在 `G:\study\AI\breeze-tts`。前一版单份对白插件已安装试用，本次更新后刷新酒馆生效，不更改后端。

## 单份输入与显示

```text
周启明拍了拍肚子。
[TTSVoice:周启明:happy:[笑]一起去食堂？]
```

插件在原标签位置显示“一起去食堂？”及播放气泡；对白放入原生 `q` 元素，跟随酒馆 `--SmartThemeQuoteColor` 引号颜色，默认橘黄色。旁白保持原样，不要求“人名：”前缀。原始聊天 `mes`、编辑器原文和原始导出都不改；历史发给模型时仍保留标签。显示内容作为纯文本插入，不执行其中的 HTML 或 Markdown。

未绑定音色仍显示完整对白，只跳过合成。显示时去除当前配置的完整语气词标签，以及历史默认四项 `[笑]`、`[叹气]`、`[咳嗽]`、`[清嗓子]`；未知方括号和未知嵌套组保留。发给 TTS 的文本不做这种显示过滤，保留原发声标签。

## 流式文字与语音时机

「连接与播放」新增「读取流式文本」，默认关闭。开启「显示为对白与气泡」时，模型输出中的未闭合标签也会隐藏角色、情绪等元数据，并逐步显示收到的对白；此时不会合成。只有外层 `]` 闭合后才成为可合成的完整标签，不按标点猜测半句话。

开启「读取流式文本」后，完整标签按自动生成／自动播放设置追加到顺序队列，不打断当前播放。关闭该设置仍实时渲染，只把自动语音延后到整条回复完成。音频「流式生成与播放」独立控制合成音频是否边传边播；两项自动开关都关闭时不会自行合成或播放。

停止、编辑、切换 swipe 或聊天会取消旧队列，旧任务完成后不会继续播放。代码区域、编辑器和原始消息不改；未闭合标签不提交语音，也不会自动补齐原文。

## 历史兼容的边界

旧回复可能在普通引号对白后紧邻一个重复标签。新模块 `dialogue-render.js` 只检查紧邻段落的引号全文，按顺序合并该段多个引号内容、归一空白并去掉已知发声标签后，完全匹配才省略重复显示、仅添加气泡。

这是保守启发式，不搜索更早段落、不做模糊或语义匹配。文字改写、额外空行等复杂格式可能仍显示两份；完整对白恰好重复也可能被误判。原文始终保留，不会因显示去重而丢失消息。其他正则若提前删除标签，可能影响定位，沿用消息下方语音条作为回退。

## 提示词及设置隔离

默认英文规则保持五条：实际发言只在标签内出现一次，旁白、动作和心理活动在外；姓名一致、情绪自然、语气词可配置，并检查所有发言及最后两次发言。用户、短信、引文、`<w2g>`、`<catsay>`、摘要及状态栏等既有排除规则保留。未绑定人物仍使用 `New`。

0.7.0-tag-render.3 加强单份对白约束：不在普通正文或第二个标签重复同一句台词，不回放前文对白（剧情中有意复述除外），并明确替代旧的双份对白示例。已绑定角色的情绪可用简短单词或贴合人物、关系及当下情境的发声短语，例如 `softly reassuring`、`playful but hesitant`；仍禁止冒号、方括号和换行。

稳定模板保留在 `settings.promptTemplate`，实验模板单独使用 `tagRenderPromptTemplate`；首次使用实验默认，保存或恢复实验模板不覆盖稳定模板。其他设置继续共用：语气词列表、音色映射、具名语料库及聊天绑定的修改不会因代码回退而自动撤销。启用有效且非空的聊天语料时仍独立追加第六条。

不要同时注入旧双份规则。新文件 `prompts/TGbreak_原思维-格式_单份对白实验版.txt` 仅调整历史兼容片段内的 TTS 要求，其余模块、宏及检查保留；旧文件未改。英文实验模板在 `prompts/酒馆_TTSVoice_单份对白实验版.txt`。用户保存的预设不会被插件自动改写。
