# Breeze 角色语音 · 0.7.0-tag-render.9（实验版）

发布分支 `main` 延续原 `experiment/ttsvoice-render`，最初从 `stable/v0.6.1` / 标签 `v0.6.1` 的提交 `60df1f8` 分出。不要与稳定版并装或同时启用，两者共用设置、事件和提示词 key。已有单份对白版可直接更新同名扩展并刷新酒馆。

模型只输出一份对白：

```text
周启明拍了拍肚子。
[TTSVoice:周启明:happy:[笑]一起去食堂？]
```

插件显示普通旁白、“一起去食堂？”和播放气泡；对白使用原生 `q` 元素，跟随酒馆主题引号颜色，默认橘黄色。原始聊天 `mes` 不变。未绑定音色也正常显示对白，仅跳过合成。显示时移除当前配置的语气词及历史默认 `[笑]`、`[叹气]`、`[咳嗽]`、`[清嗓子]`，未知方括号保留；发给 TTS 的原文保留发声标签。

历史“引号对白＋紧邻标签副本”仅在相邻段落的引号全文匹配时省略第二份显示，是保守启发式，不能识别所有旧格式。关闭插件、查看原文或导出原始消息时仍会看到标签。

点击「魔棒 → Breeze 语音工作室」管理连接、角色与音色、设计、预设和播放。音色库、流式生成、聊天映射与缓存保持原有机制，默认不自动生成或播放。

「连接与播放 → 读取流式文本」默认关闭。开启后，完整 TTSVoice 的外层 `]` 到达即可按自动生成／自动播放设置追加到顺序队列，不打断当前句。关闭时，自动语音仍等整条回复结束。该开关与音频「流式生成与播放」独立。

开启「显示为对白与气泡」时，不完整标签也会实时隐藏元数据并增量显示对白，但未闭合前不合成。停止、编辑、切换 swipe 或聊天会取消旧队列；代码和原始消息不改。

「预设注入」使用五条英文单份对白规则，动态填入角色和语气词。实验模板保存到 `tagRenderPromptTemplate`，稳定版的 `settings.promptTemplate` 不覆盖。语气词默认 47 项，中文统一方括号、英文统一圆括号，支持相邻标签拆分；原四项及 .6 混合括号默认自动升级，自定义与清空列表保留。语气词、具名语料库及聊天绑定继续共用；启用有效且非空的聊天语料时追加第六条。

不要同时注入旧的双份规范。TGbreak 其他约束保持原样；源码 `prompts/TGbreak_原思维-格式_单份对白实验版.txt` 只调整其中的 TTS 要求，旧文件保留。插件不会自动修改用户预设。

推荐在酒馆「扩展程序 → 安装扩展」中粘贴 `https://github.com/weibaozi/Sillytavern-BreezeTTS`，安装默认 `main` 分支并刷新。若原先手动安装过 `sillytavern-breeze`，先禁用旧扩展，避免新旧版本同时运行。

手动安装时，从源码目录运行：

```powershell
.\install.ps1 -SillyTavernPath 'C:\path\to\SillyTavern' -InstallExperimental
```

脚本需要显式实验开关，先备份再替换同名扩展。包名为 `dist/sillytavern-breeze-0.7.0-tag-render.9.zip`；部署应包含 `dialogue-render.js`、`automatic-queue.js` 等全部文件，刷新酒馆生效；旁白克隆还需更新配套后端并重启。

回退时从稳定源码目录重新安装并刷新，原模板仍保留。实验期间创建的单份消息不会自动转成双份；稳定版可能只显示它们的气泡，原文对白仍在。

## 旁白朗读

0.7.0-tag-render.5 需要同时更新并重启 Breeze 后端，再刷新酒馆。插件通过健康接口确认真正的克隆支持；旧后端会提示更新，不会静默按声音方向合成。角色对白仍使用原来的情绪控制，预设不变。

在「角色与音色 → 旁白声音」为当前聊天选择本地音色和模式。默认「声音克隆」沿用参考音频的语气与风格，不发送情绪指令，CFG 固定为 1；已有旁白配置没有模式字段时也默认克隆。选择「声音方向」后可编辑情绪，默认「平稳口气，配音」，沿用全局 CFG。切换模式保留已写情绪，各模式音频缓存分开。音色、模式、情绪和旁白切片目标字数随聊天保存；选择「不朗读旁白」关闭，音色失效也会跳过。旁白不加入角色名单或注入预设，不需要模型输出新标签。

消息底部控件独立于酒馆通用按钮宽度，桌面横排、窄屏整体换行。「暂停／继续」保留当前进度和剩余队列，生成中也可暂停等待；「停止」结束当前播放并清空队列，也可取消正在重新获取的任务。「重新获取」清除本条已绑定对白与已启用旁白的缓存，逐段强制重新合成（重复台词也重新请求），显示进度，完成后点击播放；不会自动发声。未绑定角色跳过，单段失败后继续处理其余片段。「播放本条」和「自动播放全文」按原文顺序穿插旁白及已绑定角色对白；单个对白气泡仍只播放该句。仅开启自动生成时也会准备旁白音频，已有缓存继续复用。旁白正文外观保持原样，只有旁白的消息也可整条播放。

旁白从正文文字提取，普通中英文引号、HTML q／blockquote 和 Markdown 引用内容也朗读；只有 TTSVoice 中的对白交给角色音色。代码、图片、链接目标地址、正文前后模块及咪咪吐槽、摘要等仍不朗读。旁白切片默认目标 100 字，可在旁白声音卡中设置 20–1000 字。跨换行、空行及 HTML 段落按目标内最后一个完整句末合并切片，计数以可朗读字符（含标点）为准，换行分隔不占目标字数；单句超过目标时保留整句，仍受 5000 字请求上限保护。换行只保留空格分隔，不单独发起请求；TTSVoice 对白边界立即切开，以维持正文播放顺序。流式读取在后续文字确定当前片段已无法继续容纳下一句时入队，结束时补读尾段；停止、切换聊天或修改旁白设置会取消旧队列。续写自动播放只读新增部分。

提取依赖文本结构，不识别所有自定义正则和 CSS 隐藏规则；自定义正文外模块需另行接入排除列表。没有 TTS 标签的引号内容统一按旁白读，不猜测说话人；历史双份对白中的普通引号副本也遵循此规则。
