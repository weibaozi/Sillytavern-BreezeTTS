# Breeze 角色语音

将本目录放入 SillyTavern 的 `data/<用户>/extensions/`，保证 `manifest.json` 直接位于扩展目录内，然后刷新酒馆。

需要配套修改后的 Breeze TTS：原 WebUI 启动并加载模型后，应能访问 `/breeze/health`。

点击输入栏左下角「魔棒 → Breeze 语音工作室」，在「连接与播放」连接 TTS；上传或设计音色，在「角色与音色」绑定角色，再点击对白气泡或启用自动播放。

格式：`[TTSVoice:角色名:情绪:[笑]对白内容]`。未绑定角色跳过合成。默认不自动生成或播放。

0.1.1 默认开启「预设注入」：每轮发送前动态添加英文规范及当前角色名单，支持开关、模板编辑、深度和预览。此功能不改写原预设文件或 TGbreak 其他模块。开启后建议关闭手工重复添加的 TTS 输出规范条目，保留 TGbreak 原有约束及允许 TTSVoice 的格式兼容规则。

0.2.0 使用独立工作室，支持手机布局与角色搜索，样式与酒馆主题隔离。更新时复制全部文件（包括 panel.js、panel.css、menu.js、prompt.js）后刷新酒馆。

0.3.0「声音设计室」新增「语音方向」：上传参考音频与准确文字，可试听参考；声音描述可留空或填写语气方向。填写新试听文本，生成 1–8 个候选，试听后命名保存。保存的音频与文字都来自选中的生成结果，不会误用上传参考的文字。原「文字设计」继续保留；直接导入已有音色仍在「本地音色库」。需要更新并重启配套 Breeze 后端。

WebUI 也可在「合成 → 已保存音色」读取这些音色，或生成、试听后创建音色；两边共用音色库。插件通过 61 项功能测试和 22 项模拟浏览器交互测试，真实模型听感需另行试听。

右键气泡清除此句缓存引用。原始聊天消息保留，隐藏标签仅作用于显示层。

0.4.0 可在「连接与播放」开启「流式生成与播放」。新对白边合成边播放，完成后仍缓存完整 WAV 供重播。支持暂停、继续、音量与停止；仅预生成仍保存完整音频。更新时复制全部文件（包括 stream-player.js），重启 Breeze 后端，再刷新酒馆。该选项默认关闭，仍等待 LLM 回复完成后开始处理。

0.5.0「预设注入」增加两栏，修改后自动保存并实时更新预览：

- **语气词列表**：所有聊天共用，默认 `[笑]`、`[叹气]`、`[咳嗽]`、`[清嗓子]`。每行一项，可编辑、清空或恢复默认；模板的 `{{vocal_events}}` 与 `{{vocal_event_example}}` 分别填入列表和示例。
- **额外语料**：开启且非空时，在最终预设末尾追加第 6 条；0.6.0 起使用下述共享语料库与聊天选择。

未经修改的旧默认模板会迁移为动态示例；自定义模板原样保留，需要保留语气词插槽才能跟随列表更新。英文模板本身仍需点击「保存模板」。本次从 0.4.0 升级只需刷新酒馆。

0.6.0 额外语料改为可命名复用的选项：

- 点击「新建并使用」，填写语料名称和内容，自动保存；其他聊天可直接选择已有语料，并独立控制是否启用。
- 编辑共享语料会更新所有选用它的聊天；「复制并使用」创建独立副本。改名保留原绑定；删除需确认，失效绑定不再注入。
- 旧版内容在打开对应聊天时自动迁移并保留原开关，旧文字也保留备份；取消绑定或删除后不会恢复旧注入。

更新须包含 `extra-prompts.js`，刷新酒馆即可，无需重启 TTS。

0.6.1 强化对白成对输出：先写正常引号对白，再追加 TTS 副本；“去引号、Markdown、旁白”仅作用于标签内。刷新酒馆会自动升级未经修改的旧默认模板，保留语料库、聊天绑定与自定义模板。已有缺失对白的回复需重新生成，不自动改写历史；本次未用真实模型验证遵循率。
